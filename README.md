# triton-ng

Rust SDK for [NVIDIA Triton Inference Server](https://github.com/triton-inference-server/server).

Provides two things:
- A safe Rust API for writing **custom Triton backends** (compiled as `.so` and loaded by Triton)
- A high-level async **gRPC client** for sending inference requests to a running Triton server

## Crates

| Crate | Description |
|---|---|
| `triton-ng-sys` | Raw FFI bindings generated by bindgen from `tritonbackend.h` |
| `triton-ng` | Safe Rust wrapper over `triton-ng-sys` |
| `triton-ng-macros` | Proc-macros for `triton-ng` |
| `triton-ng-client` | High-level async gRPC client |
| `example/custom-backend` | Example custom backend (MNIST, proxies to ONNX model) |
| `example/app` | Example client application |

## Writing a custom backend

Implement the `Backend` trait and register it with `#[triton_ng::backend]`:

```rust
use triton_ng::backend::Backend;
use triton_ng::{Context, DataType, Error, InferenceRequest, Request, Response};

struct MyBackend;

#[triton_ng::backend]
impl Backend for MyBackend {
    async fn model_instance_execute(ctx: Context, requests: Vec<Request>) -> Result<(), Error> {
        for request in requests {
            let data = request.get_input("INPUT")?.as_bytes()?;

            let mut inference = InferenceRequest::new(ctx.server(), "my_model", -1)?;
            inference.add_input_with_data("INPUT", DataType::Fp32, &[1, 10], data)?;
            inference.add_requested_output("OUTPUT")?;
            let result = ctx.server().infer_async(inference).await?;

            let mut response = Response::new(request)?;
            response
                .create_output("OUTPUT", DataType::Fp32, &[1, 10])?
                .write_fp32_vec(&result.output("OUTPUT")?.as_fp32_vec()?)?;
            response.send()?;
        }
        Ok(())
    }
}
```

### Streaming responses

A model with `model_transaction_policy { decoupled: true }` can send several
responses through a `ResponseFactory`:

```rust
let mut factory = ResponseFactory::new(request)?;
for tokens in chunks {
    let mut response = factory.response()?;
    response
        .create_output("TOKENS", DataType::Int64, &[1, tokens.len() as i64])?
        .write_i64_vec(&tokens)?;
    response.send()?;
}
factory.finish()?;
```

Call `factory.release_request()` after the last input read to let Triton
release the request and its input tensors early. The factory can still create
responses and query `factory.is_cancelled()` afterwards.

For BLS calls to a decoupled model, `Server::infer_stream` yields each result;
`Server::infer_async` continues to aggregate all results into one:

```rust
let mut stream = ctx.server().infer_stream(inference);
while let Some(result) = stream.next().await {
    let result = result?;
    for output in &result.outputs {
        consume(output)?;
    }
}
```

Dropping an `InferenceStream` before it ends cancels its BLS request on a
best-effort basis. Dropping an `InferenceFuture` does not cancel it.

### Statistics, traces and memory usage

Request and response statistics are reported automatically. Prometheus exposes
the request-level `nv_inference_*` families; model statistics JSON contains the
per-response counts and reported memory usage.

A sampled request provides a borrowed trace for custom activities:

```rust
if let Some(trace) = request.view().trace()? {
    trace.report_activity("decode.start")?;
}
```

`trace()` returns `None` when the request is not sampled or the server was built
without tracing support. Report current model or instance memory totals during
their lifecycles:

```rust
let usage = [BufferAttributes::new(MemoryType::Gpu, 0, 64 << 20)?];
instance.report_memory_usage(&usage)?;
```

Each memory report replaces the previous report at that level. Pass the full
list of memory types and devices; an empty list clears it.

Build as a `cdylib`:

```toml
# Cargo.toml
[lib]
crate-type = ["cdylib"]

[dependencies]
triton-ng = { git = "https://github.com/rdcm/triton-ng.git" }
```

See [Execution model and thread safety](docs/execution_model_and_thread_safety.md) for instances
and their runtimes, the `worker_threads` and `max_batches_in_flight` parameters, request ownership,
BLS futures, threads, cancellation, shutdown and batching.

## Using the gRPC client

```rust
use triton_ng_client::{InferInput, InferOptions, TritonClient, TritonClientConfig};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let client = TritonClient::new(TritonClientConfig::new("http://localhost:8001")).await?;

    let meta = client.model_metadata("my_model", None, None).await?;
    let n: usize = meta.inputs[0].shape.iter().map(|&d| d as usize).product();

    let response = client
        .infer(
            "my_model",
            None,
            [InferInput::fp32("INPUT", meta.inputs[0].shape.clone(), vec![0.0f32; n])],
            ["OUTPUT"],
            InferOptions::default(),
        )
        .await?;

    println!("{:?}", response.outputs[0].data);
    Ok(())
}
```

TLS:

```rust
use triton_ng_client::{ClientTlsConfig, TritonClientConfig};

let config = TritonClientConfig::new("https://triton.example.com:8001")
    .with_tls(ClientTlsConfig::new()); // uses system roots
```

## Getting started

### Prerequisites

- Rust stable
- NVIDIA driver 570+ (580+ for Blackwell / RTX 50xx)
- [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html)
- Docker

### First run

```bash
git submodule update --init --recursive
make build           # compile custom backend → target/release/libtriton_custom_backend.so
make download-model  # download mnist_onnx + create model version dirs
make docker-env-up   # start Triton (mounts .so and models/)
```

### Run the example app

```bash
cargo run --manifest-path=example/app/Cargo.toml --release
```

Triton must be running with both models in READY state.

### Run integration tests

```bash
make tests           # cargo nextest run --workspace
```

Tests require a running Triton instance (`make docker-env-up`).

### Rebuild after backend changes

```bash
make build
make docker-env-down && make docker-env-up
```
